# Agent instructions

Read and follow [`AI_GUIDANCE.md`](AI_GUIDANCE.md), the canonical contributor
guidance entry point for this repository.

If instructions conflict, follow the instruction with higher authority. Do not
copy repository guidance into this file; update the owning numbered guidance
document so every agent receives the same rules.

[`ai-guidance/10-journal.md`](ai-guidance/10-journal.md) exclusively controls
journal behavior and journal-guidance maintenance. Do not add `.journal/`
files to this repository. A journal-guidance fix made off `main` is incomplete
until its guidance commits are integrated into local `main`, its temporary
branch and worktree are removed, and the checkout is clean on `main`.
